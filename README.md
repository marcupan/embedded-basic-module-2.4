# Модуль 2.4: брязкіт контактів кнопки

Домашнє завдання курсу Embedded Basic.
Плата ESP32-S3-WROOM-1-N16R8, PlatformIO, Arduino.

## Схема

Без фільтра:

```
GPIO4 -> кнопка -> GND        (INPUT_PULLUP)
GPIO18 -> 220 Ом -> LED -> GND  (перемикається на кожне прийняте натискання)
```

З RC-фільтром:

```
3V3 -> 10 кОм -> GPIO4
GPIO4 -> 100 нФ -> GND
GPIO4 -> кнопка -> 100 Ом -> GND   (внутрішня підтяжка вимкнена, INPUT)
```

## Що робить

Одна прошивка, спосіб вибирається клавішею в моніторі порту:

| Клавіша | Спосіб |
|---|---|
| `1` | без захисту: кожен FALLING з переривання рахується як натискання |
| `2` | time-based: ISR тільки ставить прапорець, `loop()` приймає подію, якщо від попередньої прийнятої минуло ≥ 50 мс |
| `3` | state-based: ISR тільки ставить прапорець, `loop()` приймає подію, якщо кнопка досі натиснута |
| `4` | polling без переривань: пін читається кожні 5 мс, натискання приймається, якщо рівень тримається 4 читання поспіль (машина станів) |
| `u` | перемкнути внутрішню / зовнішню підтяжку (для RC) |
| `r` | обнулити лічильники |

ISR: лише лічильник, прапорець і час першого фронту. Прапорець забирається в `loop()` у критичній секції.

## Як міряв

Для кожного способу 20 натискань: звичайні, довгі (~1 с) і різкі. Усе, що понад 20, це хибні спрацювання.

## Результат

| Спосіб | Без RC: прийнято (фронтів ISR) | Хибні | З RC: прийнято (фронтів ISR) | Хибні |
|---|---|:-:|---|:-:|
| 1 без захисту | 23 (23) | 3 | 20 (20) | 0 |
| 2 time-based 50 мс | 21 (24) | 1 | 20 (20) | 0 |
| 3 state-based | 20 (23) | 0 | 20 (20) | 0 |
| 4 polling 5 мс | не міряв | — | 20 (ISR вимкнено) | 0 |

## Порівняння

| Метод | Хибні (без RC → з RC) | Затримка | Складність | Коментар |
|---|---|---|---|---|
| без захисту | 3 → 0 | одразу на першому фронті | найпростіший | рахує кожен відскок, і на натисканні, і на відпусканні |
| time-based | 1 → 0 | одразу на першому фронті | проста | при довгому натисканні брязкіт відпускання приходить пізніше за 50 мс і може зарахуватись |
| state-based | 0 → 0 | одразу на першому фронті | середня | брязкіт відпускання відкидає, бо в цей момент кнопку вже не тримають |
| polling | не міряв → 0 | не менше 4 × 5 = 20 мс | середня, машина станів | переривання не потрібне; реакція гірша за інші |
| RC-фільтр | прибирає все до піна | натискання майже одразу, відпускання на ~1,4 мс пізніше (розрахунок) | 3 деталі | брязкіт не доходить до піна взагалі, тому навіть спосіб 1 дає рівно 20 |

Затримку я окремо не заміряв: у колонці стоїть те, що виходить з коду (і розрахунок для RC).

## Чому RC спрацював

- Заряд конденсатора йде через 10 кОм: τ = 10 кОм × 100 нФ = 1 мс. До порогу HIGH (~0,75 × 3,3 В за даташитом ESP32-S3) він доходить приблизно за 1,4 мс.
- Розряд при натисканні йде через 100 Ом: τ = 10 мкс, тому натискання видно майже одразу.
- У модулі 1.5 я міряв брязкіт цієї самої кнопки логічним аналізатором: найдовший спалах 938 мкс. Це коротше за ~1,4 мс, тому за відскок конденсатор не встигає зарядитись до порогу і пін лишається в 0.

## Запуск

```
pio run -t upload -t monitor
```
